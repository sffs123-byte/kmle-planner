# 신경외과 여신 · 56문제 복습

버전: **2026-09-16.1**. 별도 빌드·서버 API 없이 동작하는 모바일 우선 정적 퀴즈입니다. 이 앱은 Anki식 정답 공개·자기평가 카드이며, 공식 Anki 앱이나 간격반복 스케줄러는 아닙니다.

## 배포 파일

- `index.html`, `style.css`, `app.js`: 앱
- `deck.js`: 검토된 56개 데이터. `window.YEOSIN_DECK = [...]` 형식
- 필요시 `assets/`: 출처가 확인된 문제 영상. 진단명·정답이 붙은 캡션을 앞면에 넣지 않습니다.

같은 디렉터리를 GitHub Pages로 제공하면 됩니다. 세 파일과 `deck.js`의 버전을 함께 배포합니다. 개인·환자정보 및 로컬 경로는 넣지 않습니다.

## 기능

- 기본은 원문 순서. 랜덤은 Fisher–Yates로 한 회차에 중복 없이 56개를 섞습니다.
- 범위·전체/다시 볼 문제·순서 변경 시 새 회차를 시작하고 기존 평가·메모는 보존합니다.
- 문제 앞면에는 문제와 답 없는 영상만 표시합니다. 정답·용어·메모·출처는 정답 공개 뒤에만 렌더링됩니다.
- “다시 볼게요” / “외웠어요” 평가 후 다음 문제로 이동합니다. 이전·다음만 누르면 평가를 만들지 않습니다.
- “현재 범위 다시 풀기”는 평가를 보존하며 새 순서/회차를 시작합니다.
- “학습 기록 초기화”는 확인창을 거쳐 이 덱의 평가·진행·선택만 초기화합니다. **다른 앱 데이터와 내 메모를 삭제하지 않습니다.**
- 현재 범위·필터·랜덤 순서·문항·공개 여부·완료 화면은 재접속 시 복원됩니다.
- 질문 문장·문제 번호 검색, 카드별 자동저장 메모, 용어 풀이, 출처 링크.
- 키보드 Space/Enter: 답 공개/숨김, ←/→: 이동. 입력·버튼·메뉴 조작 중에는 단축키를 가로채지 않습니다.
- localStorage 사용 불가·용량 초과 시 메모리 모드로 계속 진행하고 미저장 경고를 표시합니다.

## 데이터 계약

```js
window.YEOSIN_DECK = [{
  id: 'stable-id', num: 1, category: '척추·척수',
  question: '정답을 노출하지 않는 원문 질문',
  answerHtml: '<p>검토된 핵심 정답</p>',
  explanationHtml: '<p>필요한 설명</p>',
  sourceUrl: 'https://example.com/source',
  terms: [{term: '용어', definition: '정의'}],
  questionImages: [{src:'assets/image.webp', alt:'문제 MRI'}] // 선택
}];
```

`category`는 척추·척수 / 뇌종양 / 뇌혈관 / 외상·기타 같은 넓은 영역을 사용합니다. 영상 문제에서 정답 진단을 category에 쓰지 않습니다. 주 질문은 plain text입니다. answer HTML은 허용된 서식만 복사하고 script·이벤트·폼 등을 제외합니다.

## 저장 범위

- 학습 기록: `neurosurgery_yeosin_56_v1:study`
- 카드별 메모: `neurosurgery_yeosin_56_v1:memo:<id>`

localStorage는 **브라우저·기기·도메인별**로 별개입니다. 다른 기기와 자동 동기화하지 않습니다. 브라우저 데이터를 직접 지우면 메모도 사라집니다. 앱 초기화 버튼은 메모를 지우지 않습니다.

## 검증 기준

최종 덱 56개·고유 ID·앞면 정답 누출 없음, 56문항 랜덤 무중복, 답 공개·숨김, 이동·경계, 자기평가·복습 필터, 회차 재시작, 초기화 취소/확인, 메모·다른 저장값 보존, 재접속 상태 복구, storage 차단, 375px에서 가로 넘침 없음, 오류 없는 브라우저 실행을 확인합니다. 배포 후 같은 경로를 실제 URL에서 다시 검사합니다.
