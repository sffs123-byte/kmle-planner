# 신경외과 여신 완성본 · 56문제 Anki

기존 `anki` / `anki-quiz-builder` 스킬의 공용 `QuizBuilder`를 사용하는 덱입니다.
별도 카드 앱 대신 다른 과목과 동일한 Anki SRS·필기·편집 방식을 사용합니다.

## 사용

- 홈의 **전체 56문제 / 2세트 20문제 / C세트 20문제** 중 범위를 고른 뒤 **순서대로 / 랜덤 시작**.
- 실제 Anki에서 한 문제씩 풀고 **정답 보기 → 4색 SRS 평가 → 다음 문제**로 진행합니다. 단순 모아보기 화면이 아닙니다.
- 바로 풀기: `#study-set2`, `#study-setC`; 기존 `#browse-set2`도 2세트 실제 풀이로 연결됩니다.
- 첫 순서풀기는 시험지 원래 1–20번 순서이며, 복습 시점이 된 카드는 기존 SRS 규칙대로 우선 출제됩니다.
- 정답은 최신 원문 필기의 **글자색·형광펜·굵기·목록·표·접기**를 그대로 표시합니다. 요약 답은 Study Guide의 보충 답안으로 이동했습니다.
- 원문에 붙은 용어 정의는 밑줄 용어를 클릭·Enter하여 확인할 수 있습니다.
- 원문과 의학적 교정을 구분해 보충·교정 블록으로 유지합니다. 원본 운영 필기는 수정하지 않습니다.
- 세트별 학습 진도·SRS·초기화는 독립이고, **수정 답안·메모·펜 필기는 동일 카드끼리 공유**합니다. 전체56 기존 저장 키는 그대로입니다.
- 기존 요약형 수정답은 백업 후 새 원문 아래 ‘이전 Anki 수정 답안’ 접기에 보존합니다. 이후 새 수정은 그대로 저장됩니다.
- 새로고침/이어풀기는 범위·현재 문제·랜덤 순서·정답 공개 상태를 복원합니다.
- 다시 1분 / 어려움 5분 / 보통 10분(연속 2회면 숙달) / 내일 1일.
- 랜덤 첫 큐는 선택 범위 내 중복 없이 구성되며, 복습 시각이 된 카드는 다시 출제됩니다.
- 초기화는 확인 후 **선택 범위**의 학습 기록만 지우며 다른 세트·전체56 진도와 수정답·필기는 남습니다.
- 2세트10·17·18번, C세트18·19번은 영상 대신 관찰·진찰소견을 사용한 복습형 문항입니다.
- 기존 펜·형광펜·지우개·올가미 / 정답 편집 / 복사 / 백업 내보내기·불러오기를 지원합니다.
- `#browse`는 별도의 검색·참고 목록이며 실제 풀이 범위를 바꾸지 않습니다.

## 재생성

저장소 루트에서:

```sh
python3 quizzes/neurosurgery-yeosin-56/build_deck.py
```

- 내용 원본: `deck.json` (중복통합 56개, 이전 버전과 동일)
- 세트 대응: `exam-sets.json` (2세트·C세트 원문 번호↔기존 카드 ID 매핑)
- 서식 원본: `original-notes.json` (교육 필기 HTML만 추출; 댓글 작성자·시간·ID 제외)
- 기존 교정: `original-supplements.json`
- 생성기: `generate_skill_deck.py`
- 공용 UI·학습 엔진: `../anki_quiz_builder.py` (기존 skill 빌더)
- 공용 백업: `../anki_backup_restore.py`
- 이 덱 한정 보완: `deck-layout.css`, `storage-adapter.js`, `skill-adapter.js`, `browse-adapter.js`, `study-scope-init.js`, `study-scope-adapter.js`
- 결과: `index.html`, `build-qc.json`

기존 `app.js`, `style.css`, `deck.js`는 이전 버전 기록으로 보존되며 현재 HTML에서 불러오지 않습니다.
운영 노트·하단 해설·댓글·원본 PDF는 수정하지 않습니다. 환자 식별정보나 비공개 PDF는 포함하지 않습니다.
